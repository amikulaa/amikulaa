## Introduction 
Welcome to my GitHub profile! I'm Anna, a web application developer focused on building internal tools and systems that support real-world workflows. I work primarily in PHP, JavaScript, and SQL, and enjoy turning messy processes into tools that people can actually rely on.

## Projects
Here are some of the projects I've recently worked on:

### [Project 1: Invitations Management System](https://github.com/amikulaa/event_invitations)

This internal system is used by staff to send workshop invitations to speakers and organizers, track their responses through unique links, and view results in a clear, card-based dashboard. It replaces manual tracking across email and spreadsheets by centralizing the full invitation workflow in one place, making it easy to understand invitation status at a glance.

---

### [Project 2: Speaker Constraints Collection](https://github.com/amikulaa/speaker_constraints_emails)

This system manages outreach to speakers to collect scheduling constraints and availability. It sends structured emails and organizes responses in a centralized system, helping staff coordinate event logistics without relying on scattered communication or manual tracking.

---

### [Project 3: Waitlist Management System](https://github.com/amikulaa/waitlist_tracker)

This tool helps staff manage event waitlists by tracking participant status and movement in a centralized system. It replaces manual processes like spreadsheets and email chains, making it easier to maintain accurate ordering and visibility into availability.

---

### [Project 4: Web Permit Application](https://github.com/amikulaa/online-permit-application)

This online web application serves as a platform for submitting zoning permit applications. Upon receiving the existing PDF format utilized by the organization, I developed this digital application to offer a more user-friendly interface. The platform features a drawing tool, facilitates basic data retrieval, and incorporates input validation complemented by Swal alerts for enhanced user experience.

---

### [Project 5: Application Dashboard](https://github.com/amikulaa/zoning-dashboard)

The dashboard is specifically designed for an internal department to manage and process permit applications. It enables staff to review applications, make decisions such as approval or denial, and initiate communication with applicants as necessary. Key features include a graphical landing page for visual representation of data, efficient query functionality, and strong data handling capabilities.

---

### [Project 6: Web Medical Examiner Dashboard](https://github.com/amikulaa/medical-examiner)

This web application serves as the primary platform for data collection within the Medical Examiner department. It hosts forms, supports custom queries, and includes pinned reports tailored to user needs. The system also allows internal maintenance of data tables and includes training materials such as videos and slideshows.

---

### [Project 7: Graphing Page](https://github.com/amikulaa/graphing-query)

This query system was developed for a Sheriff's department to support data collection and visualization. It allows users to generate, compare, save, and print graphs using Google Charts, making it easier to analyze trends and share insights.

---

### [Project 8: Speech to Text Page](https://github.com/amikulaa/speech-to-text)

This page is designed for therapists to take verbal notes during sessions. It includes features such as automatic capitalization, punctuation handling, and controls for starting and stopping transcription.
